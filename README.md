# 「陪伴·计划」介绍站

给应用「陪伴·计划」做的单页介绍网站：计划为什么总在中间断掉，以及它怎么把碎片时间拆成今天就能做完的小动作。

- 纯静态站点：无构建步骤、无外部依赖，断网也能打开。
- 在线访问：https://jingxiuaian.github.io/
- 应用本体：https://github.com/jingxiuaian/companion-app

## 本地预览

直接双击 `index.html`；也可以起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

- 右上角按钮在「夜读灯（深色）」和「纸感（浅色）」两套主题间切换，选择记在浏览器里。
- 「打开应用」进入 `demo/` 里的应用副本，可单独使用。
- `assets/` 是应用真实截图；`tools/` 是截图脚本与验收材料。
